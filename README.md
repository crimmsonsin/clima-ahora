# Clima Ahora

Aplicación web inspirada en el reto **Weather app** de [Frontend Mentor](https://www.frontendmentor.io/challenges/weather-app-K1FiiA3h).

## Tecnologías

- HTML semántico
- CSS responsive
- JavaScript moderno con `fetch`, `async/await` y manejo de errores
- [Open-Meteo Weather API](https://open-meteo.com/)
- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)

## Funcionalidades

- Búsqueda de cualquier ciudad.
- Consulta de coordenadas mediante la API de geocodificación.
- Consulta del clima actual y pronóstico de cinco días.
- Temperatura, sensación térmica, humedad, viento y visibilidad.
- Estados de carga y mensajes de error.

## Ejecución local

Al ser una aplicación estática, puede abrirse con cualquier servidor local:

```bash
npx serve .
```
